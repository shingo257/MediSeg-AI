## 🔧 セットアップ手順

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

### 3. ビルド
```bash
npm run build
```

### 4. プレビュー
```bash
npm run preview
```
