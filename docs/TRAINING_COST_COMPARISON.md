# 学習環境のコスト比較：手持ちPC vs クラウド

MediSeg.AI の学習を「手持ちの使わなくなったPC」で行う場合と「クラウド」で行う場合のコスト比較の考え方と目安です。

---

## 1. 前提（本プロジェクトの設定）

| 項目 | 目安 |
|------|------|
| デフォルト epoch 数 | Pascal VOC: 100 / ISIC: 150 |
| バッチサイズ | 16（Pascal）, 8〜16（ISIC） |
| モデル | U-Net（〜31M パラメータ）, DeepLabV3+ |
| データセット規模 | Pascal VOC 〜1.5k 画像, ISIC 数千〜数万枚 |

※ 1 epoch あたりの時間は **GPU 性能・データ量・画像サイズ** に強く依存します。

---

## 2. 手持ちPC（オンプレ）で学習する場合

### 2.1 かかるコストの内訳

| 項目 | 内容・目安 |
|------|------------|
| **初期費用** | 0 円（すでに持っているPC） |
| **電気代** | 消費電力 × 稼働時間 × 単価 |
| **冷却・騒音** | 夏場のエアコン負荷増、ファン騒音 |
| **故障リスク** | 古いPCほど高め（データ・学習のやり直し） |

### 2.2 電気代のざっくり計算

- **想定**: GPU 搭載デスクトップ 200〜400W 増（学習時）、1kWh = 30 円
- **1時間あたり**: 0.2〜0.4 kWh × 30 円 = **6〜12 円/時**
- **例**: 1 回の学習が 24 時間 → **約 150〜300 円**
- **月に 10 回** 回すと **約 1,500〜3,000 円/月**（電気代のみ）

※ CPU のみの場合は 1 epoch が極端に長くなるため、実用上は GPU 搭載を前提にしています。

### 2.3 メリット・デメリット

| メリット | デメリット |
|----------|------------|
| 追加の従量課金がない（電気代のみ） | 古いPCは 1 epoch が遅く、総時間が長い |
| データを外に出さずに済む | 停電・故障で学習が止まるリスク |
| 何度回してもランニングコストが同じ | 最新GPUより遅いことが多い |
| ネットがなくても学習可能 | 冷却・騒音の負担 |

---

## 3. クラウドで学習する場合

### 3.1 主な選択肢と単価目安（2024〜2025年頃）

| サービス | プラン・インスタンス | GPU | 料金目安（時間あたり） | 備考 |
|----------|----------------------|-----|------------------------|------|
| **Google Colab** | 無料 | T4 など | **0 円** | 制限あり（長時間で切断など） |
| **Google Colab** | Pro / Pro+ | T4, V100, A100 など | **約 10〜50 円/時** | 月額 1,500〜3,000 円程度 |
| **AWS** | EC2 (g4dn / g5) | T4, A10G など | **約 50〜150 円/時** | 従量課金 |
| **Google Cloud** | Compute Engine (T4 / A100) | T4, A100 など | **約 50〜200 円/時** | 従量課金 |
| **Azure** | NC / ND 系 VM | V100, A100 など | **約 50〜200 円/時** | 従量課金 |
| **Lambda Labs** | GPU インスタンス | A100 など | **約 30〜80 円/時** | GPU 特化・安めのことが多い |

※ 為替・キャンペーン・リージョンで変動します。利用前に各社の最新料金を確認してください。

### 3.2 1 回の学習コストの目安（クラウド）

- **1 epoch ≈ 2〜10 分**（GPU とデータ量による）
- **100 epoch で 約 3〜17 時間**、**150 epoch で 約 5〜25 時間**
- Colab 無料: **0 円**（制限内なら）
- Colab Pro: 約 30〜500 円/回（時間とプランによる）
- AWS/GCP/Azure: 約 **150〜3,000 円/回**（インスタンスと学習時間による）

### 3.3 メリット・デメリット

| メリット | デメリット |
|----------|------------|
| 高性能GPUで 1 epoch が短い | 使った時間だけ課金がかかる |
| 自宅の電気・冷却負荷が増えない | データをクラウドに上げる必要がある |
| 停電の影響を受けにくい | ネット必須、設定・認証の手間 |
| 複数実験を並列しやすい | 無料枠は制限・切断あり |

## 4. コスト比較の考え方（いつどちらを選ぶか）

### 4.1 手持ちPCの「元が取れる」目安

- クラウドを **約 100 円/時** と仮定
- 手持ちPC の電気代を **約 10 円/時** と仮定
- **1 時間あたり 90 円の差** → 同じ学習を **約 11 時間** で終えられれば、クラウドの方が高くなる
- 手持ちPC が **11 時間以上かかる** のに対し、クラウドが **1 時間** で終わるなら、**クラウドの方がコストは安い**（時間短縮で 90 円節約）

つまり「**手持ちPC がクラウドの何倍遅いか**」で、コストの優劣が決まります。

- 手持ちPC が **10 倍遅い** → 同じ学習でもクラウドの方が総コストが安いことが多い  
- 手持ちPC が **2〜3 倍遅い**程度 → 電気代 vs クラウド課金で損益分岐

### 4.2 学習回数で見る目安

| パターン | おすすめ |
|----------|----------|
| **数回だけ試したい** | Colab 無料 or クラウド従量（手持ちは初期設定の手間が割に合わない場合も） |
| **毎週〜毎月、継続的に実験する** | 手持ちPC の電気代が月 2,000 円以内に収まるなら、オンプレは十分あり |
| **締め切り前でとにかく速く** | クラウドの高性能 GPU（A100 等）で短時間に集中 |
| **データを外に出したくない** | 手持ちPC が向く |

### 4.3 簡易チェックリスト

- [ ] 手持ちPC に **NVIDIA GPU** が載っているか（CUDA 対応）
- [ ] 1 epoch あたり **何分** かかるか、一度計ってみたか
- [ ] 学習は **何回・何ヶ月** 続けそうか
- [ ] **データの機密性**（病院データなど）はあるか
- [ ] **Colab 無料** で足りるか、Pro や他クラウドまで見るか

## 5. まとめ

| 比較項目 | 手持ちPC | クラウド（Colab / AWS 等） |
|----------|----------|-----------------------------|
| **初期費用** | 0 円 | 0 円（従量のみ） or 月額（Colab Pro 等） |
| **ランニング（目安）** | 電気代 約 150〜300 円/回（24h 想定） | 約 0〜500 円/回（Colab）〜 150〜3,000 円/回（他クラウド） |
| **速度** | 古いGPUだと遅い | 新しいGPUで速い |
| **コストが有利になりやすいケース** | 何度も回す・データを出したくない | たまにしか回さない・とにかく速くしたい |

**コストだけ**で見ると、「**学習回数が多く、手持ちPC の 1 epoch 時間がそこまで遅くない**」なら手持ちPC、「**たまにしか回さない、またはとにかく速く終えたい**」ならクラウド（Colab 無料〜Pro や他クラウド）が向きます。

実際には、**手持ちPC で 1 回だけ時間を計り**、  
「同じ学習をクラウドでやったら何時間で終わるか」を Colab などで試すと、  
「この環境なら 1 回あたり〇〇円くらい」と具体的に比較しやすくなります。
